# ⏱️ Timer Plus

복싱, 타바타, 크로스핏 등 인터벌 운동에 최적화된 고출력 짐(Gym) 타이머입니다. 
앱스토어를 거칠 필요 없이 링크 접속 한 번으로 스마트폰에 바로 설치할 수 있으며, 데이터나 와이파이가 없는 **오프라인 환경에서도 100% 정상 작동**합니다.

## 🚀 스마트폰에 어플로 설치하는 방법

아래 링크를 스마트폰의 인터넷 브라우저로 접속한 뒤, 기종에 따라 앱 설치를 진행해 주세요.
👉 **타이머 접속 링크:** [여기에 본인 깃허브 주소 입력] (예: `https://lch0307.github.io/Timer/`)

### 📱 안드로이드 (갤럭시 등)
**크롬(Chrome) 또는 삼성 인터넷 브라우저 권장**
1. 위 링크로 웹사이트에 접속합니다.
2. 브라우저 우측 상단이나 하단의 **메뉴(점 3개 `⋮` 또는 줄 3개 `≡`)**를 누릅니다.
3. 메뉴 목록에서 **`앱 설치`** (또는 `설치 및 바로가기 만들기`, `홈 화면에 추가`)를 선택합니다.
4. 바탕화면에 에메랄드빛 알람시계 아이콘이 생성되며, 누르면 100% 전체 화면 어플로 켜집니다!

### 🍎 아이폰 (iOS)
**반드시 사파리(Safari) 브라우저 사용**
1. Safari 브라우저에서 위 링크로 접속합니다.
2. 화면 하단 중앙의 **공유 버튼 (네모 위로 화살표 `↑`)**을 누릅니다.
3. 메뉴를 아래로 조금 내려서 **`홈 화면에 추가`**를 누릅니다.
4. 우측 상단의 `추가`를 누르면 바탕화면에 앱으로 즉시 설치됩니다!

## 💡 주요 기능
* **고시인성 화면 전체 반전:** 준비(노랑), 운동(초록), 휴식(빨강) 등 상태에 따라 화면 전체 색상이 변해 멀리서도 한눈에 알아볼 수 있습니다.
* **오프라인 100% 지원:** 한 번 바탕화면에 설치하면 비행기 모드나 인터넷이 없는 체육관 지하실에서도 완벽하게 작동합니다.
* **체육관 전용 고음량 사운드:** 시끄러운 음악 소리를 뚫고 나오는 맑고 강력한 복싱 벨 소리가 탑재되어 있습니다.

**※ 업데이트 안내:** 화면이 옛날 버전으로 나온다면, 설치된 어플을 지우고 브라우저 설정에서 '캐시(방문 기록)'를 삭제한 뒤 다시 접속해서 설치해 주세요!
